# AL1.1 — Bootstrap surface inventory

Per [docs/plan/bootstrap-component-tier.md](../plan/bootstrap-component-tier.md) AL1.1.

**Shipped:** `packages/exporter-bootstrap/tools/extract-surface.mjs` (paren-depth-aware parser for `_variables.scss`, CSS-var counterpart harvesting from the component partials via direct `#{$var}` interpolation), the checked-in `packages/exporter-bootstrap/surface-inventory.json`, and `scripts/check-bootstrap-surface.mjs` wired into `check:all` (regenerate-and-diff, out-reason completeness, and — dormant until AL1.2 — cross-walk completeness against `descriptors.js`).

**Numbers (bootstrap@5.3.8):** 952 top-level `$` variables; **657 in-inventory** across 49 families; 295 out-of-inventory across 8 reasoned groups (palette 146, typography foundation 41, global foundation 39, global semantic 23, feature flags 17, layout foundation 8, infrastructure 3, utility maps 2 — see the JSON's `counts`). 299 of the 657 have at least one direct `--bs-*` CSS-variable counterpart (matters for AL1.4's reach analysis).

**Delta vs the plan's ground-truth estimate (~670):** the plan's rough count merged `link`/`kbd`/`code`-adjacent globals into components using bare prefix matching. The inventory's family list is explicit: `link-*` is document-level semantics (out, `global-semantic`); `form-color-width` and `$nested-kbd-font-weight` — both missed by prefix matching — are in (new `form-color` family; an explicit alias to `kbd`). Reconciliation: 657 + the reclassified globals ≈ the estimate; the denominator is now exact rather than rough, which is the point of the task.

**Two classification calls worth recording:**

- `$component-active-bg`/`$component-active-color` are **out** — they're a cross-component active-state pair (primary.solid / on-solid shaped), shared rather than component-scoped. Flagged as a semantic-tier driving candidate for the AL1.2 findings doc rather than silently bucketed.
- `$focus-ring-*` is out because the exporter already drives it semantically (`src/index.js:144`) — verified, not assumed.

**No deviations from the plan.** The catch-all bucket (`global-other`) is empty and the check fails if anything ever lands in it.
