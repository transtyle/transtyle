## Two engine findings logged for AL2 (not fixed here — scope)

1. **Alias-to-derived-slot dangles.** Authoring `component.button.radius: "{semantic.radius.full}"` fails with a dangling-alias error: `radius.full` is derived late (from `radius.md`), after the normalizer resolves authored aliases — while aliases into the always-materialized scales (`space.*`) work fine. The component-layer sketch in ir.md uses exactly this authoring style (`{semantic.radius.interactive}`), so AL2 must either materialize scale-family slots earlier or defer component-alias resolution. Worked around with a literal `9999px`.
2. **`exporter-primeng` doesn't read `component.button.*`.** Its button values come straight from semantic grid cells, so an authored button radius changes Bootstrap but not PrimeNG — cross-target authored-component parity is a natural AL2 acceptance criterion.
