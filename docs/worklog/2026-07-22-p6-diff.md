# Worklog — P6: `transtyle diff`

**Task:** P6 (execution-2026-h2.md). A real trust/workflow feature that improves the compiler toward a good alpha without needing publication (so unaffected by the R4/R5 parking).

## Design
Diffs the **resolved semantic graph**, not token-file lines — the honest unit of a design-system change. A token rename or layer restructure with identical resolved values reports *nothing* (compiled themes are byte-identical); one authored change reports its full derived cascade across both modes. Two output layers: (1) semantic diff per mode (added/removed/changed slots with before→after values + hex, and a provenance-only change note), (2) per-target impact by re-emitting both sides in memory and diffing the artifacts (`usage.md` excluded).

## Implementation
- `packages/core/src/diff.js` — pure `diffResolved(before, after)` (no I/O); exported from core.
- `compile()` now returns `emitted` (file specs) per target result even when `emit:false`, so diff re-emits without writing or rebuilding ctx.
- CLI `cmdDiff`: resolves "before" via `git archive <ref> | tar -x` into a temp dir, "after" = working tree; `--json`, and `git diff`-style exit codes (0 identical / 1 changed / 2 error).
- `docs/specs/diff.md` (the spec); cli.md moves `diff` from Specced → Implemented (docs guard now counts 6 commands); golden tests added to `scripts/check-cli.mjs` (git-init temp repo: no-change→0, change→1 + slot + impact, `--json` parseable, bad ref→2).

## Two real bugs caught during verification
1. **macOS symlink:** `git rev-parse --show-toplevel` returns the realpath (`/private/var/...`) but `mkdtempSync` yields the symlink (`/var/...`), so `path.relative` produced a broken `../..` prefix and diff silently found nothing. Fixed by taking the project prefix from `git rev-parse --show-prefix` (symlink-independent).
2. **stdout truncation:** `process.exit(1)` immediately after a ~39 KB `console.log(--json)` truncated the async write to a pipe — would have corrupted real CI consumers. Fixed by setting `process.exitCode` and letting the process end naturally.

Both were caught because the golden test captures stdout via spawnSync (a pipe), unlike a TTY/file-redirect where they hide.
