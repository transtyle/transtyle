# AL1.2 — The Bootstrap binding cross-walk

Per [docs/plan/bootstrap-component-tier.md](../plan/bootstrap-component-tier.md) AL1.2.

**Shipped:** `packages/exporter-bootstrap/src/descriptors.js` (the full binding table: 79 emit recipes, 108 explicit drop classifications, mechanical rules for chained/follows-global/`null`-marker variables); `check:bootstrap-surface` extended with cross-walk completeness (every in-inventory variable classified, no double-classification, no dangling names) **and** recipe-path validation against a real Acme compile (a typo like `sem: 'space.7'` fails CI, not AL1.3); the component-theming section in [docs/specs/exporters/bootstrap.md](../specs/exporters/bootstrap.md); [docs/findings/bootstrap-component-crosswalk.md](../findings/bootstrap-component-crosswalk.md) (classification stats, six AL2 promotion candidates with PrimeNG cross-references, the five contested calls).

**The numbers:** 657 in-inventory → 79 emit / 287 chained / 140 follows-global / 43 inherit-default / 51 dropped / 57 unsupported. 84% driven-or-following; the 57 `unsupported` are itemized growth data, not silence.

**Deviations from the plan:** one, minor. The plan said to work "family by family in descending variable count (forms first)" — the actual order was driven by the root-vs-chained split computed from the inventory (230 roots needing judgment; 427 variables mechanically classified), because the split turned out to do most of forms' work for free: the big form families are dominated by chained and `null`-marker variables. Same coverage, cheaper route; recorded per process rule 4.

**Two findings worth flagging beyond the docs:**

- PrimeNG's exporter hardcodes `disabledOpacity: '0.6'` with a comment saying no Transtyle equivalent exists; Bootstrap's cross-walk produced 12 `unsupported` opacity slots. The state-opacity ladder now has two independent consumers before AL2 even starts.
- `$component-active-bg`/`$component-active-color` (out-of-inventory, semantic-shaped) are currently undriven — flagged in the findings doc as a cheap semantic-side pickup for AL1.3.
